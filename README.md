# ByteRyte

ByteRyte is a fundamentals trainer for Java, with JavaFX and HTML/CSS branches and a Swift side track. Print questions were checked by running them on JDK 21. Swift snippets were checked against the Swift.org language guide, and the other explanations against Oracle, OpenJFX, and MDN. Gems are in-app only.

Open `index.html` in a browser, or visit the GitHub Pages site at https://angel-adames.github.io/ByteRyte/.
